# Game entity reference

Source-grounded inventory of every square and card definition in both edition scripts, plus the player model and included AI. Classic is loaded by the page; New York City exists in source but is inactive. Each concrete board index and card deck slot has its own Markdown document. Shared mechanics are in [Gameplay rules](gameplay-rules.md).

**Coverage:** 2 character/player pages; 80 board-square pages (40 per edition); 64 card pages (16 in each deck per edition). UI colors and images are cosmetic, not character implementations.

## Inventory notes and limitations

- index.html loads classicedition.js; the New York City include is commented out (index.html:8-12). NYC documentation records source coverage, not an active shipped mode.
- Both edition sources define 40 distinct squares and 32 distinct cards; matching indices do not make entities interchangeable.
- NYC tax helpers call undefined addalert; active engine defines addAlert.
- corrections() is defined in each edition source but has no repository call site.
- Game source was not modified. Each entity page links its source definition line and relevant shared rules.
