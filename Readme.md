# monopoly

A JavaScript/HTML/CSS Monopoly implementation with full game play. Supports two-eight players.

Play online at [http://www.intrepidcoder.com/projects/monopoly/](http://www.intrepidcoder.com/projects/monopoly/).

Includes an experimental capability to play against an AI. A test AI for demonstration purposes is included.

See the [source-grounded game entity reference](docs/game-reference/README.md) for the implemented player model, board squares, cards, and shared gameplay rules. It covers the active classic edition and the inactive New York City edition source.
